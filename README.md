# Golf Atlas: US golf course map prints by state

A plain list of the US golf courses drawn by [Golf Atlas](https://golfatlasmaps.com/). Each course has a map print
showing all 18 holes, fairways, greens, bunkers and water, made from OpenStreetMap data and checked against public
aerial photos. Prints are PDFs that fit 12x16, 18x24 and 24x32 inch frames.
